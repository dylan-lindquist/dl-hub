# Photos

Drop family photos in this folder (`.jpg`, `.png`, `.gif`, or `.webp`).

- The board rotates through whatever is here, in filename order, one every 20 seconds.
- Landscape shots work best (the slot is wide).
- Keep them reasonably sized (under ~1–2 MB each) so the page stays quick on the old iPad.
- No photos here = the bottom-left shows a plain coloured panel instead. That's fine.

To add one: on GitHub, open this `photos` folder → **Add file → Upload files** → drag the image in → **Commit changes**. The board rebuilds and the new photo appears at the next refresh.
